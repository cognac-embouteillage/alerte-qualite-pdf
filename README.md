# Alerte Qualité PDF

Application web du service qualité de Prestations du Fief : alerte client en cas de défaut critique ou majeur sur une production.

- Photo de l'OF et de la fiche palette → lecture des codes-barres (n° d'OF, batch, date, code semi-fini) et du libellé, directement sur le téléphone.
- Qualification du défaut, quantités et calcul automatique du taux.
- Photos commentées, rapport PDF numéroté `PDF-QUA-E-0035-AAAAMMJJ-HHMM`.
- Envoi via l'appli mail de l'iPhone (Mail / Outlook) avec le PDF joint.

Aucune donnée n'est stockée en ligne : l'historique est conservé sur chaque appareil.

Publication : Settings → Pages → Deploy from a branch → `main` / `(root)`.
